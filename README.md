# ZapretHub

Приложение для Windows (окно в стиле Windows 11 и значок в трее) поверх [zapret](https://github.com/bol-van/zapret) (`winws.exe`) со стратегиями [Flowseal/zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube).

## Что умеет

**Обход блокировок**
- Главная страница: статус и главный переключатель, карточки модулей, лента событий. В трее остаются только «Открыть», «Вкл/Выкл» и «Выход».
- Подбирает рабочую стратегию автоматически, на странице «Обход» с прогрессом и результатами по каждой стратегии.
- Игровой фильтр как у Flowseal: Выкл / TCP / UDP / TCP+UDP. IPSet всегда полный, режим «any» не используется.
- Находит конфликт с другим обходом (служба `zapret`, `winws`, GoodbyeDPI) и предлагает его остановить.

**Игры (страница «Игры»)**
- Профиль игры включается и выключается переключателем на карточке, как модуль.
- Правила Flowseal «game filter + ipset any» применяются только к адресам и портам этой игры, так что другие сервисы не ломаются.
- Адреса запоминаются через «обучение»: выбираете процесс игры, нажимаете «Запись», играете.
- Серверы Amazon (EC2/GameLift) расширяются до своих региональных диапазонов.

**Telegram (страница «Telegram»)**
- Встроенный [tg-ws-proxy](https://github.com/Flowseal/tg-ws-proxy) от Flowseal. Он работает от вашего пользователя, без прав администратора.
- Кнопка «Подключить Telegram к прокси» открывает ссылку `tg://proxy`, и Telegram добавляет прокси сам.

**VPS (страница «VPS»)**
- Подписка (например, из панели 3x-ui) или ссылка одного сервера: VLESS (TLS, Reality, ws, gRPC, httpupgrade, HTTP/2), Hysteria2, Trojan, Shadowsocks. Работает через [sing-box](https://github.com/SagerNet/sing-box). XHTTP и VMess пока не поддерживаются.
- Подписка обновляется сама по интервалу, который задаёт панель (по умолчанию раз в 12 часов). Показываются трафик и срок действия.
- Ссылка подписки и серверы хранятся зашифрованными (DPAPI текущего пользователя) в папке, доступной только администраторам.
- Два режима:
  - «Весь трафик через VPS»: всё идёт через сервер, кроме российских сайтов (наборы правил geoip-ru и category-ru) и игр с маршрутом «Напрямую». Включается на главной, на странице VPS и в трее.
  - Выборочный: через VPS идут только отмеченные категории («Заблокированное в России», нейросети, YouTube, Discord, Telegram и другие), программы и сайты.
- Автовыбор сервера: раз в 5 минут приложение сравнивает пинг серверов и переключается на заметно более быстрый без перезапуска туннеля. Пока запущена игра из профилей, проверка не идёт.
- Сервер, настройки которого sing-box не принимает, пропускается с предупреждением и не ломает остальные.
- У игры есть маршрут: «Напрямую», «Через VPS» или «Авто». В режиме «Авто» при запуске игры приложение сравнивает оба пути и выбирает лучший. Путь держится до следующего запуска игры.
- «Качество канала»: пинг, джиттер и потери напрямую и через VPS. Замер делается на уже открытом соединении с TLS-серверами игры, поэтому оба пути сравниваются честно.

**Обновления**
- При запуске приложение проверяет новые версии стратегий Flowseal, TG WS Proxy и sing-box.
- Устанавливает их только после вашего подтверждения, по уведомлению или кнопке в «Настройках».
- Каждый файл сверяется с SHA-256 из GitHub. Если новая версия не запустилась, возвращается прежняя.

**Прочее**
- Запускается вместе с Windows через планировщик задач, без окна UAC при каждом входе, сразу свёрнутым в трей.

## Сборка

```bash
dotnet publish src/ZapretHub.App -c Release -r win-x64 --self-contained false -o publish
```

Запуск: `publish\ZapretHub.exe`. Попросит права администратора, они нужны драйверу WinDivert. Повторный запуск открывает окно уже работающей копии.

Предпросмотр интерфейса без прав администратора (страницы с тестовыми данными в PNG):

```bash
dotnet run --project tools/UiPreview -c Release -- ui-preview
```

## Где лежат данные

`%ProgramData%\ZapretHub\`. Папка защищена: писать в неё могут только администраторы, так как приложение запускает оттуда программы с правами администратора.

| Путь | Что это |
|---|---|
| `engine\versions\<версия>` | распакованные релизы Flowseal, проверенные по SHA-256 из GitHub |
| `user\lists\*-user.txt` | ваши списки доменов и IP, обновления их не трогают, редактировать можно без прав администратора |
| `user\targets.txt` | цели для автоподбора (формат Flowseal: `Имя = "https://..."`) |
| `settings.json` | настройки |
| `logs\app.log` | лог |

Файлы в `user\` можно менять, но нельзя удалять или создавать новые: так никакая программа не сможет подменить папку и заставить приложение писать от имени администратора. Редактируйте файлы «на месте» в Блокноте. Редакторы, которые сохраняют через временный файл (например, VS Code), получат «Отказано в доступе».

Списки адресов игр (`games\`) доступны только администраторам. Открывайте их через меню «…» на карточке игры → «Открыть список адресов».

При включении автозапуска приложение копируется в `%ProgramFiles%\ZapretHub`, и задача планировщика запускает эту копию.
